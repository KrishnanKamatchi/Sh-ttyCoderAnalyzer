# 💩 Sh*ttyCoderAnalyzer

> Because deep down, every developer is a little bit... *sh*tty.*

A brutally honest, humor-fueled, dev personality analyzer that judges you based on how much chaos you bring to your commits.
Think Buzzfeed quiz meets StackOverflow meltdown.

---

## 🚀 What is this?

This is a **web app built with React + Tailwind** that asks you a series of ridiculous, dev-related questions.
You answer truthfully (or not), and it spits out your **developer archetype** — from *Junior PleasantCoder* to *Nuclear Dev*.

It’s funny, raw, slightly offensive (if you opt-in), and completely useless in a productive sense.
But hey, it makes you laugh — and maybe question your life choices.

---

## 🧠 Features

- 🔥 10–15 dev-themed questions: sarcasm, chaos, caffeine — all included
- 💀 “Raw Mode” — for people who think code reviews are personal attacks
- 🎉 Animated result card with roast messages
- 🧻 Shareable meme generator (coming soon)
- 🧙‍♂️ Simple, client-side only (no backend magic... yet)
- 🪦 0% serious, 100% accurate
